Runtime dependencies

PackageVersionPurposeWhy this one
drift 2.35.4 Typed SQLite database: tables, migrations, foreign keys and reactive watch queries. Folders, quizzes, questions and attempts are relational and must update live. Drift gives typed queries, cascades and streams without hand-written SQL plumbing.
drift_flutter 0.3.1 Opens the Drift database on Android, iOS and desktop with the correct app-data path and SQLite libraries. Removes platform-specific database setup from main() and keeps the data layer portable.
file_picker 13.4.1 Native file picker used to choose one or more quiz .json files. The PRD requires file-based import. It covers Android, iOS and Windows with one API.
intl 0.20.3 Formats attempt dates, times and durations in the history list. Small, official Dart package; avoids hand-written date formatting and locale mistakes.
uuid 4.6.0 Generates stable string IDs for folders, quizzes, questions, options and attempts. The architecture requires stable IDs. UUIDs avoid collisions and keep import and navigation independent of auto-increment counters.
flutter_math_fork 0.7.4 Renders inline TeX / LaTeX in question prompts and options, e.g. \(2^{29}\), \times. The quiz content is mathematical. The package is a maintained pure-Dart fork of flutter_math, with the widest KaTeX compatibility.

Dev dependencies

PackageVersionPurposeNotes
drift_dev 2.35.3 Generates the Drift table, query and database code. Must match the drift runtime version.
build_runner 2.17.1 Runs drift_dev code generation. Standard build tool; generated files are committed so the app builds without an extra step.
integration_test SDK End-to-end tests for the main journey on a device or host. Ships with Flutter; no third-party test runner.
flutter_lints Template Recommended Flutter lint set. Included by flutter create and kept for flutter analyze.
mocktail 1.0.5 Optional test doubles where a hand-written fake would be longer. The architecture prefers hand-written fakes; mocktail is only for the few interfaces that are awkward to fake.

Deliberately not added

Package / areaDecision
provider · riverpod · bloc · getxNot needed. The architecture uses ValueNotifier, ViewState and constructor injection.
go_routerNot needed. The app has a simple folder → quiz → attempt stack; Navigator is enough.
dio · httpThe app is fully offline. No network calls at runtime.
sqflite · hive · isarDrift is the single storage choice; adding another database would duplicate persistence.
shared_preferencesTheme follows the system; all persistent data lives in the database.
freezed · json_serializableModels are small and hand-written; no second code generator beyond Drift.
path_providerdrift_flutter already handles paths.
url_launcher · share_plusSharing and external links are out of scope for the MVP.

Version compatibility

Flutter was upgraded to 3.50.1 / Dart 3.14.0 on 22 Nov 2026, so the newest release of every package is available. flutter doctor reports no issues. Resolved versions are recorded in pubspec.lock and committed.

SDK change: this is a global upgrade from 3.35.7. The app is new, so no project migration is needed; other local projects will also use Flutter 3.50.1 from now on.

Install commands

flutter pub add drift drift_flutter file_picker intl uuid flutter_math_fork
flutter pub add dev:drift_dev dev:build_runner dev:mocktail
flutter pub add dev:integration_test --sdk=flutter
dart run build_runner build --delete-conflicting-outputs
flutter analyze

Versions are resolved by pub for Dart 3.14.0. The resolved versions are recorded in pubspec.lock and committed.

Risks and fallbacks

flutter_math_fork maintenance

Last published May 2025; Apache-2.0; pulls provider and flutter_svg transitively (not used by app code). It is still the standard pure-Dart TeX renderer. Fallback: a small Unicode formatter for the limited TeX subset in the quiz files.

Drift code generation

Adds a build step. Generated *.g.dart files are committed, so a fresh clone and flutter run work without running build_runner. CI and tests verify the generated code is current.

Math fallback: if flutter_math_fork does not compile on this Flutter version, the app will ship the Unicode formatter instead of blocking the whole setup. This is the only package with a pre-approved fallback.
