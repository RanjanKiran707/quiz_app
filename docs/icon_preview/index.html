Safe zone

  • Mark centred with ~22% padding.
  • Android adaptive foreground keeps the mark inside the central 66%.
  • Masks above are previews; the installed iOS icon is unmasked.

Known limitations

  • This page is a preview; no launcher icon is installed.
  • The selected master will be exported for Android, iOS and Windows.
  • Small-size checks use browser downscaling of the 1024 px master.
